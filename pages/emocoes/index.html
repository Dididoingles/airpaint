O AirPaint usa bastante memória para reconhecer expressões faciais. No celular ele pode travar ou ficar lento. Abra no computador para a experiência completa.

Permitir acesso à câmera?

Para detectar suas expressões, o AirPaint precisa acessar sua webcam. O vídeo é processado no seu navegador e não é enviado para nenhum servidor.

  • Sorria para detectar "happy".
  • Franza a testa para "angry".
  • Abra bem os olhos para "surprised".

Como usar o AirPaint — Emoções

O app reconhece três emoções com boa precisão (happy, angry, surprised) e tenta também captar sad. Faça a expressão e veja o nome em inglês aparecer na tela.

  • Happy: sorria.
  • Angry: testa franzida.
  • Surprised: olhos bem abertos.
  • Sad: canto da boca para baixo. É a mais difícil de detectar — não se preocupe se não aparecer.
  • Use "Sortear um desafio" para receber uma emoção-alvo (happy, angry ou surprised) e tentar reproduzi-la.
